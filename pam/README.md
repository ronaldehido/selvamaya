# PAM Selva Maya dashboard

Sube todo el contenido de esta carpeta a:
`ronaldehido.github.io/selvamaya/pam/`

## Archivos editables principales

- `index.html`: página principal.
- `about.html`: página de proyecto, participantes e instituciones.
- `assets/css/styles.css`: colores, tipografías y diseño.
- `assets/js/app.js`: carga CSV, gráficos, fotos y fichas.
- `data/activity_daily.csv`: actividad diaria para dos especies.
- `data/top_species.csv`: top 10 especies.
- `data/example_detections.csv`: ejemplos con audio.

## Imágenes y audio

- Reemplaza `assets/img/banner.jpg` por tu banner real.
- Guarda audios en `assets/audio/` o usa URL externa en `audio_url`.
- En `photo_url` puedes dejar vacío para intentar foto automática con iNaturalist.
